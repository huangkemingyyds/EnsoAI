# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues in `J3n5en/EnsoAI`.

## Conventions

- Create issues in GitHub Issues.
- Apply `ready-for-agent` when a PRD or issue is fully specified and ready for an AFK agent.
- Read existing issue context before updating or splitting work.
- Keep PRDs in issue bodies unless the user explicitly asks for a separate document.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in `J3n5en/EnsoAI`.

## When a skill says "fetch the relevant ticket"

Read the GitHub issue, including comments and labels.
